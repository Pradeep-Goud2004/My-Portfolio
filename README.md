# Pradeep — Premium Interactive Portfolio

Built from the uploaded Premium Portfolio — Tech & Design Stack specification, using React, Tailwind CSS, GSAP motion, scroll-driven animation, micro-interactions, immersive 3D/depth presentation, responsive UX, optimized portrait assets and a Vite production workflow.

## Run
```bash
npm install
npm run dev
```

Open the exact Local URL printed by Vite.

## Important
Use the root folder that directly contains `package.json`, `index.html`, `src`, and `public`. Do not run the project from an older nested copy.

### Profile photo interaction
Hover over the profile photo to start a smooth continuous 360° rotation. Moving the mouse over the photo adds subtle 3D tilt and parallax. When the cursor leaves, the photo smoothly returns to its starting position.
